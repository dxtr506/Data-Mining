# Voi Kruger: dùng Decision Tree để tìm tập tính di chuyển của voi từ dữ liệu GPS

Dự án môn học Khai phá dữ liệu, dựa trên bài báo Thaker và cộng sự (2019) (`fevo-07-00004.pdf`).

**Bắt đầu đọc tại [`elephant_dt/README.md`](elephant_dt/README.md)**: giải thích dự án làm gì, cách xử lý dữ liệu, cách tìm pattern, cách suy ra tập tính và cách dùng giao diện web.

Muốn xem demo ngay: mở `elephant_dt/web/index.html` bằng Chrome hoặc Edge.
